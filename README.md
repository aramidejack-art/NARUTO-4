# CI note (read this if GitHub Actions fails)

**Error:** `Unable to access jarfile .../gradle/wrapper/gradle-wrapper.jar`

**Cause:** `./gradlew` was run but `gradle/wrapper/gradle-wrapper.jar` is not in the GitHub repo
(often forgotten when uploading files, or blocked by a root `.gitignore` with `*.jar`).

**Fix in this pack:**
1. Workflow uses **Gradle 8.1.1 from the action** (`gradle build`) so it does **not** need the wrapper jar.
2. `.gitignore` explicitly keeps `gradle/wrapper/gradle-wrapper.jar`.
3. Still commit the wrapper jar if you want local `./gradlew` to work for everyone:
   `git add -f gradle/wrapper/gradle-wrapper.jar && git commit -m "Add gradle wrapper jar"`

# ShinobiCraft v0.5.1 — The Anime Update (Forge 1.20.1)

Anime-style unarmed combat for Minecraft Forge 1.20.1 (Forge 47.2.0, Java 17).

> **IMPORTANT: this version has never been compiled.** It was written without access to the Forge/Mojang
> servers, so it was only syntax-checked and API-checked against Forge source. Build it and expect to fix a few
> vanilla method names. Please send me the compiler errors and I will fix them.

## Build
    ./gradlew build        # jar appears in build/libs
    ./gradlew runClient    # test in dev

## Controls (rebindable)
| Key | Action |
|---|---|
| R | **Toggle Combat Mode.** While ON, left click (M1) throws the strike chain (jab > cross > hook > knee > roundhouse) no matter what you hold; vanilla attacking and mining are disabled. Sprint = dash strike, look up = uppercut, sneak = sweep, roundhouse on airborne target = spike. Press R again to go back to vanilla |
| V | Dodge (flash step; perfect dodge triggers a cinematic counter) |
| B | Guard (hold) / perfect parry |
| G | Leap + dive ground slam |
| X | Ultimate: Barrage. Shift+X: Meteor (100 momentum) |
| Z | Lock-on / blitz flash-step to target |
| K | Status |

## Features
- Server-authoritative combat with cone targeting, line-of-sight, lock-on and blitz teleports.
- Launches, juggles, wall slams, ground crashes, spike craters, hit-stop.
- Cinematic camera for Barrage, Meteor, perfect-dodge counters and finishers, with letterbox, speed lines, comic text, flashes and shake.
- Destruction with hardness limits, spawn protection, mobGriefing and a block budget; debris is cosmetic and never re-places blocks.
- Telegraphed mob lunges at mob level 2+, progression, momentum meter, 10 synthesized sounds.

## Config
`mayhem-server.toml` (combat, destruction, mobs, ultimates) and `mayhem-client.toml` (cinematics, shake, FOV, letterbox, HUD, hold-to-attack).
Turn off cinematics or destruction there if you dislike them.

## Test checklist

5. Barrage and Meteor cinematics end and restore camera/HUD (relog if the camera sticks). 6. Multiplayer join/leave.
